# Tabdeal USDT Live Trading

نسخه‌ی **بازار مارجین تتری (USDT-quoted)** پروژه‌ی `abdeal-live-trading` — دقیقاً همون
دو بات (Supertrend+ADX + ICT/SMC، هر دو استراتژی، دو-لاتی، معکوس‌سازی در بات۱)،
فقط به‌جای بازار تومانی (IRT) روی جفت‌ارزهای تتری تبدیل (مثل `BTCUSDT`) اجرا می‌شن.

## تفاوت با ریپوی تومانی
- همه‌ی نمادها/بازارها با `USDT` ختم می‌شن (`BTCUSDT` به‌جای `BTCIRT`).
- کشف بازار مارجین‌دار (`discover_all_usdt_margin_bases`) روی جفت‌های تتری کار می‌کنه؛
  استیبل‌کوین‌های دیگه (USDC/BUSD/DAI/TUSD/FDUSD/...) به‌طور پیش‌فرض از فهرست حذف می‌شن
  چون نوسان معناداری در برابر تتر ندارن.
- مبلغ‌ها همه به **تتر** هستن، نه تومان.
- منطق سیگنال (`signal_bot.py`/`signal_bot_v2.py`)، معماری دو-لاتی + Breakeven، رصد
  بازه‌ی High/Low (به‌جای قیمت لحظه‌ای تک‌نقطه‌ای) و چک سرمایه‌ی آزاد نسبت به موجودی —
  همه‌شون عیناً از ریپوی تومانی کپی شدن، بدون تغییر منطقی.

## پیش‌فرض‌های فعلی (قابل تغییر با GitHub Variables)
| Variable | مقدار پیش‌فرض کد | توضیح |
|---|---|---|
| `TABDEAL_DRY_RUN` | `true` | همیشه اول با این تست کن |
| `TABDEAL_HARD_CAP_MARGIN_USDT` | 30 | سقف امنیتی مطلق هر معامله |
| `PAPER_STARTING_BALANCE_USDT` | 100 | موجودی فرضی شروع |
| `BOT1_MARGIN_USDT` / `BOT1_LEVERAGE` | 10 / 3x | مارجین و اهرم Supertrend+ADX در بات۱ |
| `BOT1_SMC_MARGIN_USDT` / `BOT1_SMC_LEVERAGE` | 10 / 1x | مارجین و اهرم ICT/SMC در بات۱ |
| `BOT2_ST_MARGIN_USDT` / `BOT2_ST_LEVERAGE` | 10 / 3x | مارجین و اهرم Supertrend+ADX در بات۲ |
| `BOT2_SMC_MARGIN_USDT` / `BOT2_SMC_LEVERAGE` | 10 / 2x | مارجین و اهرم ICT/SMC v2 در بات۲ |

⚠️ این‌ها فقط **پیش‌فرض کد** هستن (وقتی Variable گیت‌هابی ست نشده باشه). برای اجرای
واقعی حتماً همه‌شون رو صریحاً توی GitHub → Settings → Secrets and variables → Actions بساز،
دقیقاً مثل کاری که برای ریپوی تومانی کردی.

## راه‌اندازی (قدم‌به‌قدم)
1. این ریپو رو توی گیت‌هاب خودت بساز (public یا private) و همه‌ی این فایل‌ها رو push کن.
2. Secrets بساز: `TABDEAL_API_KEY`, `TABDEAL_API_SECRET`, `TELEGRAM_BOT_TOKEN` (بات۱),
   `TELEGRAM_BOT_TOKEN_2` (بات۲ — می‌تونه یه بات تلگرام جدا باشه).
3. Variables بساز: جدول بالا + `TELEGRAM_CHAT_ID` و `TELEGRAM_CHAT_ID_2`.
4. قبل از فعال‌کردن اجرای خودکار، یه‌بار دستی از تب Actions → workflow_dispatch اجرا
   کن و مطمئن شو خطایی نمی‌ده و پیام تلگرام درست می‌رسه.
5. برای اجرای خودکار دوره‌ای، از cron-job.org (یا مشابه) استفاده کن — گیت‌هاب اکشنز
   دیگه کرون داخلی نداره (طبق تجربه‌ی ریپوی تومانی، غیرقابل‌اعتماد بود).
6. بعد از چند روز تست در `TABDEAL_DRY_RUN=true`، اگه نتیجه رضایت‌بخش بود، برای رفتن به
   حالت زنده (`TABDEAL_DRY_RUN=false`) با کمترین مبلغ ممکن شروع کن.

## نکات تاییدنشده (هنوز با API واقعی و کلید واقعی تست نشدن)
- اینکه بازارهای USDT-quoted تبدیل واقعاً از طریق همون `create_margin_order`
  (با `tabdealSymbol` زیرخط‌دار مثل `BTC_USDT`) قابل معامله‌ن، فقط از روی مستندات
  و ساختار `get_all_assets()` استنتاج شده — قبل از حالت زنده حتماً با یه معامله‌ی
  خیلی کوچیک دستی تایید کن.
- بازپرداخت خودکار وام بعد از بستن پوزیشن با سفارش معکوس (مثل ریپوی تومانی، هنوز تایید نشده).
- ساختار دقیق پاسخ `trades()` (برای رصد بازه‌ی High/Low) با API واقعی تست نشده؛ اگه
  فرمتش فرق داشت، کد خودش fallback می‌زنه به قیمت لحظه‌ای (بدتر نمی‌شه، فقط دقتش کمتره).
